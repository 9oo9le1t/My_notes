### 1. Network Forensics
* **Wireshark & Tcpdump Anomaly Detection:** Identifying Command & Control (C2) beaconing patterns, decoding Base64 strings within DNS TXT queries (DNS Tunnelling), and detecting covert network scanning techniques.

### 2. Windows & Active Directory Security
* **Lateral Movement Analysis:** Identifying internal brute-force attempts and Pass-the-Hash (PtH) techniques.
* **Kerberos Authentication Logic:** Analyzing standard ticket lifecycles (AS-REQ -> TGS -> AP) to spot domain-wide anomalies (Kerberoasting, AS-REP Roasting).

### 3. Malware Analysis & Threat Hunting
* **Behavioral & Traffic Analysis:** Tracking live malware execution and mapping out its covert network footprint.
* **Advanced Threats:** Understanding Living off the Land (LotL) concepts, fileless malware (Resident in RAM), and process injection mechanisms.
